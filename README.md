China in Numbers — an original national statistics explorer for China, entered in make.fun's [Make the best national statistics site](https://make.fun/bounty/best-national-statistics-site-20261126-0539) bounty. Six linked pages (overview, population, economy, living standards, regions, and an interactive year explorer) present real figures from the National Bureau of Statistics of China's 2024 Statistical Communiqué and the 2015–2024 annual series, with hand-drawn SVG charts, a searchable and sortable provincial GDP table, and a year slider that recomputes per-capita GDP live. The site is plain static files under `app/` — no build step, no network requests — and runs on desktop and phone.

## Run it

```sh
node serve.ts          # then open http://localhost:8080
node main.ts           # writes app/, screenshots/ and dossier.json to /output
```
